# CASIN_CodeToPublication

Code Repository for paper: Targeting CDC42 with CASIN Reprograms Cell Type Specific Transcriptomes and MAPK Driven Transcription Factor Networks in the Aging Brain
The raw sequencing data generated in this study is available from ArrayExpress with the identifier E-MTAB-14889 and TBD. Detailed metadata, processed seurat objects, counts, differential analysis sheets, all helper objects, can be found on Zenodo with the DOI 10.5281/zenodo.21621060.
